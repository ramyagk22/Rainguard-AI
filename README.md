# RainGuard-AI 🌧️

## Project Overview
RainGuard-AI is a smart rainfall prediction and alert system.  
It helps users prepare for weather changes by giving timely alerts.

## Installation
1. Clone repo: `git clone https://github.com/ramyagk22/Rainguard-AI.git`
2. Navigate: `cd Rainguard-AI`
3. Backend run: `python app.py`
4. Frontend run: `npm start`

## Usage
- Open browser: `http://localhost:3000`
- Enter location → get rainfall prediction.
